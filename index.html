🚀 Инструкция по подключению к копитрейдингу

Вводная информация: Чтобы подключиться к сервису копирования сделок, нужно зарегистрироваться у брокера, настроить правила копирования, создать счёт и пополнить его на сумму от $1000. После пополнения копирование начнётся автоматически.
Как пользоваться инструкцией: последовательно выполняйте шаги. После завершения каждого шага отметьте галочку «Выполнено» в его заголовке — это автоматически откроет следующий шаг.
0 / 3 шагов
1 Регистрация у брокера
  • Укажите страну проживания, электронную почту и пароль.
  • Либо авторизуйтесь через аккаунт Google/Facebook.
  • ⚠️ Нет вашей страны в списке? — выберите ближайшую; при проверке документов система укажет верную.
Перейти к регистрации
2 Верификация
⚠️ Требования по верификации зависят от страны: где-то нужно пройти сразу, где-то — только при пополнении счёта (для разблокировки доп. способов). Если после перехода ничего не увидите — не пугайтесь, для вас верификация будет на этапе пополнения.
⚠️ Планируете пополнять криптовалютой? Верификацию можно пройти позже — при первом выводе средств.
  • Подтвердите личность: паспорт или водительское удостоверение.
  • Подтвердите адрес: любой документ с ФИО и адресом (коммунальные счета, интернет, мобильная связь, банковская выписка).
Пройти верификацию
3 Настройка копирования и пополнение счёта
  • Введите сумму инвестирования в долларах США (USD) — не менее $1000.
  • Обязательно: откройте «Больше настроек» → включите «Выполнить масштабирование после того, как лидер закроет свои сделки» (остальные параметры не трогать).
  • Прокрутите вниз → в разделе «Счёт»: «Создать новый счёт» → «Копировать» — откроется страница пополнения.
  • Пополните счёт на указанную сумму (не менее $1000).
  • Выберите способ: банковская карта или криптовалюта.
  • Нет нужного способа — система предложит верификацию для разблокировки.
  • После пополнения копирование начнётся автоматически.

📱 Подключение счёта к MetaTrader 4 (необязательно)

На указанную при регистрации электронную почту придёт письмо (возможно в спам) с данными от нового счёта. Вам понадобятся:

  • Логин (номер счёта)
  • Инвесторский пароль (только для чтения)
  • Название сервера (например: EGlobalTrade-Classic3)

Скачайте платформу для вашего устройства:

💻 Windows 🍎 iOS 🤖 Android
Как подключиться (пошагово):

📱 Android:

  • Откройте приложение MetaTrader 4.
  • Нажмите меню ≡ (слева вверху) ➔ «Управление счетами» ➔ значок «+».
  • Выберите «Подключиться к существующему счету».
  • В строке поиска введите название Сервера и выберите его из списка.
  • Укажите Логин и Инвесторский пароль ➔ нажмите «Войти».

🍎 iOS (iPhone):

  • Откройте приложение MetaTrader 4.
  • Перейдите в «Настройки» (внизу справа) ➔ нажмите на «Торговый счет» ➔ значок «+».
  • Выберите «Подключиться к существующему счету».
  • В поиске найдите и выберите название Сервера.
  • Укажите Логин и Инвесторский пароль ➔ нажмите «Войти».

💻 Windows (ПК):

  • Запустите терминал MetaTrader 4.
  • В верхнем левом меню нажмите Файл ➔ «Подключиться к торговому счету».
  • Введите Логин и Инвесторский пароль.
  • В поле Сервер выберите нужный сервер из списка (или введите его имя вручную).
  • Нажмите «Логин».

💡 Примечание: Инвесторский пароль обеспечивает безопасность. Вы сможете в реальном времени видеть открытые позиции, историю сделок и баланс, но функции открытия/закрытия сделок и вывода средств с этим паролем заблокированы.
